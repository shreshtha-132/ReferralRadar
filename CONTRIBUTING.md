# Contributing to ReferralRadar

Thank you for your interest in contributing! ReferralRadar is an open-source project and we welcome contributions of all kinds: bug fixes, new features, UI improvements, and documentation.

## How to Contribute
1. **Fork the repository** on GitHub.
2. **Clone your fork** locally: `git clone https://github.com/shreshtha-132/ReferralRadar.git`
3. **Create a new branch** for your feature or bugfix: `git checkout -b feature/your-feature-name`
4. **Make your changes** and test them locally using `pytest tests/`.
5. **Commit your changes** with clear, descriptive commit messages.
6. **Push to your fork** and submit a **Pull Request (PR)**.

## Issue Template
If you are opening an issue for a bug, please include:
- A clear description of the issue.
- Steps to reproduce the behavior.
- Your OS and Python version.
- Any relevant logs or screenshots (but **do not include API keys**).
